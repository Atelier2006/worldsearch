# worldsearch

アスユイの VRChat お気に入りワールドを、売り場（カテゴリ）と検索で辿るためのサイト。

🔗 **公開URL**: https://atelier2006.github.io/worldsearch/

## 機能
- 目的から探す: 一人でのんびり / V睡したい / フレンドと遊ぶ / 初めての人を案内 / 写真を撮る / 音楽・ライブ / 物語・体験に浸る / Questで行ける（タグをもとに全売り場から集める。「まだ行ってない」は除く）
- 売り場の切り替え: 展覧会系 / パーティクル / 雑多 / 本当におすすめ（最初に開く売り場） / まだ行ってない / チルワ / ゲムワ
- ワールド名・タグ・説明・定員での検索（`/` キーで検索欄へ）
- 「絞り込み・並び替え」: タグ（多い順に8件＋もっと見る）、並び替え、写真/一覧の切り替え。絞り込み中の条件は個別に外せて、まとめてクリアもできる
- 今日のワールド（日替わり）、まずはこの5件（`index.html` の `STARTER` で差し替え可）、おまかせで1件開く
- カード: 説明の1文目、売り場ごとの種類、人気・Quest対応/PC専用のバッジ、タグ3件。写真が読めないときは売り場の色と名前を表示
- 詳細: 紹介 → こんな人に → 行く前に（注意点） → くわしく → 人数などのデータ → タグ → 関連ワールド。「VRChatで開く」は画面下に固定。← → で前後に移動
- 説明文（`note`）は、VRChat の公式説明（`official`）と X・紹介記事などの情報をまとめた1つの文章。公式説明は別枠では出さない（`official` は同期と見直し用に残している）
- 表示状態はURLに残るので、そのまま共有できます

## 構成
| ファイル | 役割 |
|----------|------|
| `index.html` | サイト本体 |
| `data.js` | ワールド／カテゴリのデータ。**ここを編集するだけで追加・更新できます** |
| `assets/js/core.js` | 検索・絞り込み・並び替え・詳細表示などの処理 |
| `assets/css/custom.css` | テンプレートへの上書き（和文フォント・横幅・タイルの見え方など） |
| `assets/css/main.css` ほか | テンプレート本体（無改変） |
| `tools/notes.html` | 説明文の見直し用（自分用）。サムネイルと説明文を並べて見て、その場で直せる。直した分はブラウザに保存され、「直した説明文を書き出す」で JSON に。ブラウザの印刷で PDF にもできる |
| `tools/apply-note-edits.js` | 書き出した JSON を `data.js` の `note` に反映する: `node tools/apply-note-edits.js <ファイル>`（確認だけ）→ `--write` で書き換え |

## ワールドの追加方法
`data.js` の `WORLDS` 配列にオブジェクトを追記し、`note`（説明欄）を書くだけです。
新カテゴリは `CATEGORIES` に1行足し、対象ワールドの `category` をその id に設定します。
